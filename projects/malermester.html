About the project

The painter's customers mainly find him through word of mouth and Facebook, where his posts showed great before and after photos but no clear way to request a quote. The goal was a simple, trustworthy website that works well on a phone, presents his services and lets potential customers contact him directly.

I designed the pages in Figma and then built the site from scratch in plain HTML, CSS and JavaScript without frameworks or a CMS.

Key decisions

As a small one-man business, the client did not want monthly costs. Instead of a hosted CMS, I built the site as a static website deployed on Cloudflare Pages, which is free and updates automatically from GitHub. The contact form uses a form service, so requests go straight to his inbox without a server. The only fixed cost is the domain.

Because new projects must be easy to add, all gallery and carousel content lives in one data file, so a new project is added by placing the images in a folder and adding a few lines.
